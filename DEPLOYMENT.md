# Streamlit Community Cloud Deployment

1. Open the GitHub repository: https://github.com/qxiao2ub/AI_Math_Mentor
2. Replace or upload the files from this ZIP at the repository root.
3. Confirm that `app.py`, `math_mentor.py`, and `requirements.txt` are at the root, not inside an extra wrapper folder.
4. In Streamlit Community Cloud, select the repository and branch.
5. Set the main file path to `app.py`.
6. Deploy or reboot the existing app.

Live app domain: https://math-ai-mentor.streamlit.app/

No API key or Streamlit secret is required for this self-contained prototype.
